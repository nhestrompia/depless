# Debounce migration acceptance check

Copy `tests/fixtures/debounce-migration` to a disposable directory and run `npm ci`, `npm test`, and `npm run build`. The checked-in fixture stays on Lodash so the baseline can be repeated. Its only use is a 12 ms trailing call with latest arguments, pending `cancel()`, and pending `flush()`; it does not use leading calls, `maxWait`, callback `this`, or a return from the debounced function.

After the developer selects `timing/debounce`, run the registry public tests and the Lodash differential tests for the documented overlap. Build and preview the pinned registry item, including source, license, destinations, and diff. Install it into the disposable consumer, switch to its named `debounce` export, and run consumer tests and build. Remove Lodash through npm only after these checks pass, then run them again and inspect imports, manifest, and lockfile. If any relevant check fails, restore the Lodash source and dependency and report the exact failed behavior per the replacement workflow.
